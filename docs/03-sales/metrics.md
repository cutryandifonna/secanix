# Metrics

## Funnel metrics

| Metric | Target awal (30 hari) |
|---|---|
| Free scan dijalankan | 200-500 |
| Finding serius per scan (rata-rata) | tracking, bukan target — indikator value produk |
| Conversion free → Pro | 2-5% (standar PLG awal) |
| Conversion Pro → Team | tracking, belum ada target — tunggu volume Pro cukup |

## Distribusi

| Metric | Target awal |
|---|---|
| Impression thread Twitter/X | tracking per post |
| Upvote/komentar Reddit | kualitatif — insight dianggap berharga atau tidak |
| Product Hunt ranking hari launch | top 10 kategori (realistis buat launch pertama) |
| Install/star GitHub Action | tracking, indikator distribusi organik |

## Kualitatif

- Testimoni real dari user yang nemuin finding serius.
- Feedback false-positive — pantau ketat, ini yang paling gampang bikin churn.

## Cara pakai

Review metrics tiap akhir minggu selama 30 hari pertama. Kalau conversion rendah, cek [funnel.md](funnel.md) dan [../02-marketing/positioning.md](../02-marketing/positioning.md) sebelum nambah fitur baru — kemungkinan besar masalah di pesan, bukan produk.
